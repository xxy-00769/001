本次未自动烧录、未固化Flash。旧发布包保留。先测试2.1修复版；只有原图失败时，再用2.1B作一次对照。不要求重做已确认的基础接线，不带电插拔摄像头。

## 一次旁路对照（仅2.1原图失败时）

下载 `FPGA_GSV1_M2_02_2_1B_RESTORE_VIDEO.sbit`，重复步骤2～4，保持相同接线、720p源和动态内容。两版唯一功能差别是 PROCESSING_ENABLE=1/0；B版完全移除处理模块，KEY6保持原图，勿用B版验收滤镜。

- 2.1原图失败、2.1B原图通过：范围缩到处理链/其物理实现相关影响；不等于已证明某个滤波算法根因。
- 两版原图都失败：说明去掉处理硬件不足以消除异常，优先继续公共DDR/采集/板级采样路径；不再盲改算法或连发位流。
- 2.1原图及其他模式通过：使用2.1，B版不需下载；报告观察时长和是否有原下半段闪动。

回传：版本、视角、原图/处理、观察时长、首个失败步骤，以及“2.1/B 两版是否同样异常”。异常照片/视频尽量包含OSD，说明内容区还是固定外黑边。新版本所有真实画面和闪动改善均待本次用户实测。
