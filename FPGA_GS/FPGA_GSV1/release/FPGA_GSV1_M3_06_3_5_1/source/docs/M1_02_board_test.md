# M1-02 1.1 用户上板观察

本文件是待执行的用户测试，不是已通过的板上记录。烧录文件和 SHA256 以 `release/FPGA_GSV1_M1_02_1_1/release.json` 为准。代理不会连接 JTAG、烧录或固化 Flash。

1. **断电接线。** CAM0/cmos1 固定前摄；CAM1/cmos2 固定后摄，后摄可用用户准备的延长排线。沿用原双目模块接口方向，确认排线接触和锁扣。HDMI-OUT 接 MPI7001，显示 800×480。完成接线再上电，用户自行通过 JTAG 加载新 SBIT；本轮不写 Flash，不带电插拔摄像头。
2. **启动。** 等待摄像头配置和完整帧就绪。左上角应为黄色“前摄”，中央为前摄实景；LED4 默认亮（停车），右上角复位无提示。图像是 640×360，位于 (80,60)，周围黑边属于设计留白。图内下方不应出现额外整块置黑、错行或其他来源。
3. **固定前摄 30 秒。** 不按任何键，先移动前摄前的物体，再遮住前摄。画面应跟随前摄并被遮暗。保持前摄不动，移动/遮挡后摄，当前前摄画面不应闪入后摄内容。重点观察上次照片圈出的图内下方。
4. **切换并长按。** 按 KEY5，应在帧边界显示后摄，左上角变为“后摄”，右上角出现 `KEY5 视角切换`，约 2 秒后消失。KEY5 持续按住 3 秒只切换一次，松开后再次按下才再切换；意图 LED 不受 KEY5 影响。
5. **固定后摄 30 秒。** 不再按键；移动/遮挡后摄应只影响后摄画面，遮挡前摄不能闪入前摄。隐藏前摄期间移动其前面的物体，随后切回前摄，应看到更新后的实景，而非旧画面冻结。对后摄也做一次同样的隐藏后重选。
6. **反复切换。** 每次完整松开 KEY5，间隔约 0.2～1 秒，切换十余次。标签必须与实际被遮住的镜头对应；不应夹入上一来源像素或留下图内下部错块。没有有效完整帧时允许等待黑画面，不允许用另一摄像头填补。
7. **KEY1～4 与 LED。** 依次按 KEY1、KEY2、KEY3、KEY4：LED1、LED2、LED3、LED4 应依次互斥保持；右上角分别显示 `KEY1 左转请求`、`KEY2 右转请求`、`KEY3 直行请求`、`KEY4 停车请求`。约 2 秒消失，期间按新键应替换文字并重新计时。长按不重复触发。
8. **停车优先。** 保持 KEY4 按下，再按 KEY1/2/3：LED4 继续亮，文字必须带对应键号及“停车优先请求未生效”。松开 KEY4 后重新按 KEY3，LED3 应亮并显示直行请求。
9. **KEY6。** 按下显示 `KEY6 处理待接入`。本轮无滤镜，KEY6 不切换处理模式、不改变意图 LED。物理引脚已接 J19，需用户确认实际按键对应。
10. **亮度与异常区域。** 本版仅在显示端使用逐色饱和 1.25 倍增益，黑白端点保持，原始 DDR 图无改动。比较相近光照下的实景，确认亮度和色彩可接受；增亮不应被视为黑块/串源修复证据。原设计黑边仍在，图内下部应保持正确连续内容。

若失败，回传烧录版本、前/后标签、按键序列、是否固定视角无按键也发生、两个镜头分别遮挡时的现象及同一区域照片。先保留当前现象，不进入 M2，不固化 Flash。真实 DDR PHY、外部 IO 与延长排线的稳定性仍以本轮用户实测为准。

开发者原图旁路：`fpga_gsv1_top.DISPLAY_GAIN_ENABLE=0` 或 `m1_display_gain.bypass=1`；正式 1.1 默认增益开启，KEY6 不绑定旁路功能。
