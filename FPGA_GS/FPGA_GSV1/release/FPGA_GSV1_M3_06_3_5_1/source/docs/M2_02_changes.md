# M2-02 2.1 修改与验证边界

M2-01 2.0 已由用户上板判定失败；本版是修复候选，未由执行端烧录或上板确认，不进入 M3。

## 实际改动

- `rtl/display/m2_rd_buf.v`：先以已有像素寄存器`en_d[0]`/`fs_d`驱动DDR域同步器，阻止组合raster/来源译码毛刺形成假行credit或假SOF，不改变像素数据路径。显示 SOF 遇旧命令仍 busy 时进入 discard_line；保持旧命令排空和 owner 的旧帧槽保护，禁止旧拍写入新帧环形段，旧 done 不再推进新帧地址。无旧命令时原有预取、抽样和保护不变。
- `rtl/display/m2_filter_row.v`、`m2_processing.v`：两行改为显式 GTP_DRM18K。row1 同端口 READ_BEFORE_WRITE；row2 在下一拍把 row1 旧值写到延迟列，另一端口同步读当前列，避免跨端口同址冲突。两行各 2 个 DRM、0 个存储 FF；总流水仍 4 拍，因果 3×3、窗口首两行/列旁路和接缝隔离保持。
- `rtl/display/m2_video_output.v`、`rtl/board/fpga_gsv1_top.v`：将正式显示时序、读调度、来源选择、增益、处理、OSD和输出寄存器收进同一模块供工程与联合检查共用。内部 PROCESSING_ENABLE 编译参数为 0 时 generate 不实例化 m2_processing，以 4 级 47bit 元组传递 RGB/HS/VS/DE/image/x/y；OSD明确原图。正式版参数1，唯一对照版参数0。
- `flow.tcl`、`scripts/build.ps1`：加入新模块，隔离快照构建 2.1 / 2.1B；记录旁路参数及准确快照哈希。时钟、DDR频率、布局种子和约束未调整。
- `sim/m2_full_tb.sv`、`m2_bypass_tb.sv`、`m2_epoch_tb.sv`、`m2_ram_contract_tb.sv`：补全720行组合、四拍编译旁路等价、跨SOF旧返回、实际厂商宽度转换契约检查。

## 原有功能保持

三路独立完整帧缓存、持续采集、CAM0前/CAM1后/HDMI左固定映射、KEY5四视图、正式版KEY6五模式、中文OSD、六键消抖和长按单次、停车优先和四LED、原显示增益。DDR仍保存原始RGB565。未改变相机/HDMI寄存器、引脚或图像区域，未关闭欠载保护，未加入网络、Flash或新算法。

## 有界环形读出核对

Native地址是32bit word：每行1280 RGB565 = 640 words = 80个256bit拍；每拍地址+8。单画面读源行0/2/…/718，行步长1280 words；田字格读0/4/…/716，步长2560 words。每行消费640 words，半缩放步长1、四分之一缩放步长2、320次；9bit写地址和12bit读地址均在4096 words处回绕。

Credit以行开始计数，最多保留“仍在扫描的一行+后面两行”，总3840源像素，小于8192像素RAM，尚未扫描完的一行不会因该credit提前覆盖。新检查核对生产完整尺寸、多次回绕和真实行完成；并非把平均带宽当作任意DDR延迟的保证。任意长停顿仍由现有保护置黑，故障帧不显示错误数据，后续SOF恢复。

## 仿真边界

完整组合使用实际三份 monitor/capture_pipe/fram_buf/owner/native控制、三端口仲裁及正式 m2_video_output；三路1280×720，双摄约42.0168MHz（异相）、HDMI74.25MHz、DDR100MHz、面板29.545454MHz，输出800×480。采集激励摄像头1892×740、HDMI1650×750；HDMI数字输入/EDID适配器本轮未修改，其上版独立记录保留。

DDR BFM使用共享256bit数据服务日历，写5/8、读3/8，禁止同拍读写占用；地址通道独立，包含地址同拍首拍、拍间隙和末拍延迟。它验证控制/数据打包与服务竞争，不模拟加密DDR PHY或真实板级延迟。

长组合为运行效率使用等价行RAM模型；实际生成读/写RAM另作三轮全地址打包和一拍延迟核对，滤波采用真实GTP原语作614400像素定点参考核对。厂商生成仿真副本只把无敏感信号的 always@(*) 机械替换 always_comb 以执行t=0常量求值，生产IP原封保留。行为模型通过不代表板上通过。

## 新确认的CDC机制与证据

原DDR同步器直接采组合rd_en/rd_fsync；源域二进制译码的亚像素脉冲可能被另一个100MHz域看作真实事件。定向注入2ns脉冲跨DDR边沿、避开像素边沿：修复前实际一行被计成两行；像素零SOF被计成一次DDR SOF。前者会虚增预取credit、允许环形写端追上未消费行；后者可中途复位DDR指针/owner而像素读指针不复位。完整尺寸相同夹具另做旧同步源失败对照，日志随发布。

修复复用现有像素寄存器，不新增显示数据延迟，只让DDR侧事件与真实像素域采样一致。真实SOF和行credit到DDR多一个像素周期约33.85ns，远小于行预取裕量，帧束稳定时间增加。最终完整组合注入16个行译码脉冲和1个SOF译码脉冲，像素域输入帧/行不变，要求生产输出仍正确。

**2ns是测试激励，不是现场测量；未声称测得板上真实毛刺、其幅度或频率，也不声称这是现场唯一触发原因。** 确认的是可复现的数字事件错误及其修复，板上仍按一次原图/A-B验收。
