# M3-02 3.1 实现与验证边界

## 显示

新增rtl/display/m31_timing.v、m31_video_output.v、m31_rd_buf.v、m31_processing.v、m31_filter_row.v、m31_osd.v、m31_text.v、m31_pixel_pll.v；生产top选HD_DISPLAY分支。旧M2/3.0显示模块和发布快照保留，未开发双屏运行模式。

CEA总时序2200×1125，HS44、后沿148、活动1920、前沿88；VS5、后沿36、活动1080、前沿4，正极性。交付74.25MHz/30Hz，AVI VIC34及对应checksum。50MHz配置/25MHz摄像头时钟维持原PLL；新增像素PLL50/10×297/20=74.25MHz，使用最后一个PLL，合计5/5。

帧缓存仍720p RGB565。读完整1280源像素行：80个256bit beat，native地址步长640个32bit word。单视图逐行读取720行，高/低半字逐像素选择，未丢弃奇列。四格读取540行，源行/列floor(4*n/3)，步进1、1、2；未通过旧640/320宽缓存缩小后再放大。环形RAM仍8192像素，三个预取行加扫描行最多5120像素，完成判定基于真实命令完成。保留像素域注册CDC、跨SOF旧返回丢弃和排空后复位、独立帧槽保护和欠载保护。

30Hz四格显示DDR读约165.888MB/s；两摄各720p30、HDMI720p60、右摄5及前摄上传5fps，加上显示，纯像素总计约405.504MB/s，不含命令/刷新开销。控制器100MHz×256bit理论3.2GB/s，仅为预算，不等于实测带宽。完整显示用例仍给读侧仅3/8数据服务时间并插合法间隙。

滤波两行升级2048×24，每行3个物理DRM18K（2048×9，24有效bit），合计6 DRM，不映射成大规模FF。原定点算法与四拍处理延迟保留，坐标升级11bit，窗口边界960/540。像素选择后新增一拍寄存，断开来源选择→增益→色度计算长路径，同步/坐标/模式一起延迟；新增两拍OSD元数据/字形分级，像素、DE、HS/VS、区域与告警颜色同步延迟。读取RAM两拍后到最终输出共八拍（选择1、处理4、OSD2、输出1）。

## 文件与发送

已有FFmpeg解码；fps滤镜按源时间戳重采样，等比例scale/pad，输出1280×720 rgb565le。独立解码线程仅保存最新完整帧，发送队列容量1；发送慢则跳过旧帧，不积压整个视频。暂停停止媒体时间推进、发送静帧；EOF与停止区分；循环由FFmpeg执行。没有安装依赖、下载素材或发送压缩字节。

实测3.0图案生成约34.63ms，1440次138.9us等待累计约838.99ms，是约1fps主因。图案黑字遮罩改批量字节操作；封包预分配；独立发送进程精确逐包限速，避免接收线程GIL竞争和Windows等待粒度。没有无界突发追赶。代价是发送时可占用一个CPU核心，统计给准备/发送/等待/排队耗时。

GSV3头长/分片/MTU不变。HEARTBEAT flags bit0=1表示新增统计：frame_id=板端右摄完整发布计数，offset=组装丢帧计数，sequence=bad_packets。仅心跳复用这些字段，按键/判定绑定语义不变；多余残片不会重复算成多个丢帧。计数为32bit模回绕，主机从首次心跳差分平均，不能跨机器时间戳直接推单向延迟。

发送IPv4头先计算校验和、再建立90字节头快照、最后移位发送，避免ti索引→校验和/大选择器→TX的长组合路径；原图载荷的暂存/所有权/发送完成释放不变。

## 端点

config/m3_endpoints.json是当前PC IP、FPGA IP、MAC、UDP端口及业务归属入口；scripts/configure_m31_endpoints.py仅生成RTL常量，不配置系统网络。生产top传给共享栈。当前两类业务同一网口/会话，未来分流方案集中记录为未集成；没有声称已实现独立双链路会话。

## 检查边界

完整1080生产显示用例使用四份完整1280×720 DDR快照、独立来源/坐标图案、生产读RAM/命令/仲裁/缩放/处理/同步路径，逐像素检查单视图和四格的整个1920×1080输出。DDR服务BFM限制读带宽/返回间隙。它没有重新实例化传感器捕获和实际PHY，四路持续捕获及双读者另以已验证基线和必要所有权回归覆盖；不冒称一次全顶层物理DDR/PHY组合验收。

长扫描采用契约等价RAM/字形常0模型（OSD区域/元数据仍生产RTL）；真实vendor256写/32读RAM和全部新字形流水另测。vendor仿真沿用既有Icarus适配：仅临时副本将无敏感量always@*改always_comb，使常量片选在零时刻初始化，生产IP不变。定点滤波使用真实DRM模型与独立参考，覆盖全宽和两类窗口接缝。

60秒软件回环由仿真对端产生前摄/控制/心跳，**不是FPGA板端实测**。测试视频均为本地生成夹具，不是道路素材。镜头焦距/光照、显示器兼容、PHY电气及外部IO完整时序签核仍需实际设备验证。
