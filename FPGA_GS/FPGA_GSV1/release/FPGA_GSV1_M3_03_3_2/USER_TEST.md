# M3-03 3.2 最短上板验收

本轮交付标准1920×1080p60完整功能版：148.5MHz，2200×1125，正HS/VS，AVI VIC16。没有交付1080p30版本。代码、数字检查和构建通过不等于显示器兼容性已验收。

## 同屏同线先验格式

1. 保持原27B1显示器与同一根HDMI线。板HDMI-OUT直接接27B1，勿接HDMI-IN。先保持电脑设置不变。确认加载的是本包3.2位流；按板卡原流程上电/复位并自行下载，不写Flash。
2. 等待DDR和MS7210初始化。屏应出现中文/实景，不再显示“输入不支持”；打开显示器自己的信息页，应识别1920×1080、60Hz。此项通过才继续画质与网络验收。
3. 若仍“输入不支持”/无信号/频率异常，记录实际位流名、屏信息页和开机现象。不要用改变电脑HDMI-IN的分辨率代替修复板输出。此时兼容性仍失败，下一步需读板端MS7210状态或测PCLK/HS/VS/DE，勿先做M4。

60Hz为HDMI输出刷新率，不代表网口右摄60fps。保留已有发送参数；先5fps后手动试15fps，分别看请求、电脑完整发送、板端发布和前摄接收，不能拿刷新率代替网络性能。

## 电脑与工具保持原用法

电脑HDMI-OUT→板HDMI-IN仍是**扩展屏1280×720@60Hz，RGB8bit/SDR**，与板HDMI-OUT→27B1的1080p60是两条独立链路。工具放电脑主屏。

网口1继续使用原有手动配置：PC192.168.50.1/24，板192.168.50.2，UDP50000，1Gbps。不要改已有可用网络配置；网口2未接入。本轮没有安装任何依赖或自动改网络。

cd E:/zhoumian/FPGA/FPGA_GS/FPGA_GSV1
python -X utf8 tools/m3/console.py --bind 192.168.50.1 --board 192.168.50.2 --video "E:/videos/road.mp4" --loop --ffmpeg "E:/ruanjianji/FlyingMouse/FlyingMouse Format/resources/ffmpeg/ffmpeg.exe" --right-fps 5 --front-fps 5 --auto allow --stats m32_board_stats.json

视频路径换成自己的现有文件，FFmpeg参数指向自己的已安装程序；不带--video为测试图。GUI保留文件选择、暂停/循环、前摄原尺寸和保存PNG。未重新优化或重新测本轮软件吞吐；历史软件回环请求5/15fps实际约4.88/13.31fps，不代表板端性能。
