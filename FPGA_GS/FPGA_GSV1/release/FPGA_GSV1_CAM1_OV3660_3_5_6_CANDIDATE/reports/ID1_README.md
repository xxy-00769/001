# CAM1 ID1：3.5.5 TXDET1基线上的只读型号检查点

这不是CAM1花屏修复版。TY-OV3660-75MM-V2.0尚无确切厂家针脚表，实物芯片ID尚未取得；不能宣称模块通用或电气兼容已确认。

## 核对与修改

工作副本取自已发布3.5.5 TXDET1，不取项目根目录的历史改动。原包及回退位流不变。原两路配置均为OV5640表且不核查ID/ACK；这说明现配置不能证明适用于新模块，尚不是此次花屏唯一根因证据。

本候选仅将CAM1配置改为只读SCCB：等待原复位流程完成，两次读取0x300A/0x300B，检查四阶段ACK、重复读一致性、超时并通过现有115200串口报告。总线7位地址0x3C，写地址0x78、读地址0x79。只写寄存器指针，不写寄存器数据。

CAM1配置完成保持为0，不发布帧。因此后摄窗口暂时没有实景是此型号检查阶段的预期行为，不是用置黑掩盖花屏交付。CAM0/HDMI/DDR/滤镜/协议/PHY/PLL/RGMII生产源码保持；网络文件仅增加现有UART的被动状态透传。完整硬件功能尚待实测。

## 资料边界

原厂OV3660 PRELIMINARY v1.3资料确认DVP、RGB565、原生720p、24MHz在支持时钟范围内，芯片电源范围包含板端名义值。但该资料参考24针模组与本板部分针脚不同，不能用其替代用户TY模组引脚表，也不能据此认定TY模组不兼容。精确板端针脚与出处见interface_audit.md；模组连接器兼容性仍未确认。不要求改变现有接线或反复上电试错。
