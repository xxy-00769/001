# M2-01 2.0 用户测试

本版由用户自行通过 JTAG 下载发布包中的新 SBIT；不烧写 Flash。旧 M1-02 1.1 包保留。以下是验收步骤，尚不是板上通过记录。

## 接线与电脑设置

1. 断电连接 CAM0 前摄、CAM1 后摄（继续使用实际延长排线）。板子 HDMI-OUT → MPI7001。
2. 电脑 HDMI-OUT → 板子 **HDMI-IN**。两条 HDMI 线必须分别接输入和输出接口。
3. 上电并下载 M2 新 SBIT。Windows 按 Win+P 选择“扩展”，打开“设置 → 系统 → 屏幕”，识别新增显示器。EDID 名称为 GSV1-720P；建议下载完成后再插一次电脑到板子的 HDMI 线，让电脑重新读 EDID。
4. 选择该扩展屏，分辨率设为 **1280×720**，在“高级显示”选择 **60Hz 或 59.94Hz**，关闭 HDR。显卡允许设置时选 RGB、8bit、全范围。核对“活动信号模式”也是 1280×720，不能只是桌面逻辑分辨率720p、实际输出1080p。程序不会自动修改电脑设置。
5. 将带大号编号、明显红绿蓝白色块、移动物体的普通桌面或本地视频拖到扩展屏。不要用受 HDCP 保护的视频作为首测输入。FPGA 输出仍是 800×480，小屏内容区640×360，位于(80,60)，黑边属于设计。

## 操作、正常现象与失败判据

| 操作 | 正常现象 | 失败现象 |
| --- | --- | --- |
| 默认上电，不按键观察30秒 | 前摄实景，左上“前摄/原图”，默认 LED4 停车；活动图上下区域连续更新 | 只显示后摄/电脑、长期无图、下半区域闪黑或跳变 |
| 分别遮挡 CAM0、CAM1 | 前摄只随CAM0遮挡改变；隐藏后摄仍采集 | 另一镜头影响当前画面、切换后停留在很久以前的图 |
| KEY5短按一次 | 后摄实景；“KEY5 后摄”提示约2秒；遮挡CAM1改变画面 | 标签与镜头不符、串入前摄或电脑画面 |
| 再短按KEY5 | 左摄显示电脑编号/视频；提示“KEY5 左摄” | 无信号提示长期不消失、错色/缺行、出现相机图像 |
| 再短按KEY5 | 田字格：左上前、右上后、左下电脑、右下“右摄待接入”；每格320×180 | 三格复制同一路、窗口错位、接缝出现另一路条带 |
| 再短按KEY5 | 回前摄；循环前→后→左→田字格→前；每次在帧边界生效 | 长按自动反复跳转、帧内中途变来源 |
| 三路场景都在运动时切换20次 | 每路持续更新，未选中的来源再次选中仍有较新的完整画面 | 隐藏来源永久停采、重新选中长期黑屏、相邻来源混入 |
| KEY6依次短按5次 | 灰度→3×3均值去噪→二值→三栏Y/Cb/Cr灰度→原图；右上显示实际KEY6和模式，左上保持状态 | KEY6无变化、模式名与效果不同、文字被滤镜变灰/模糊 |
| 对照各模式 | 灰度无彩色；均值仍为彩色并平滑细节；二值只有黑白；分量模式每个窗口分三栏，依次Y、Cb、Cr灰度；原图恢复已有显示增益 | 把YCbCr当成RGB产生彩色伪色、田字格边界混色、处理改变其他输入的采集 |
| 田字格的均值模式，给三个来源不同颜色 | 每格内部滤波，接缝不混入邻格颜色；每格前两行/列为原图边界 | 接缝有另一摄像头颜色、顶部残留上一窗口内容 |
| 分别按KEY1/2/3/4 | LED1/2/3/4分别左/右/直/停，单灯保持；右上为实际键号和请求 | LED映射不对、多个意图灯同时保持、提示键号错误 |
| 按住KEY4再按KEY1/2/3 | 保持LED4；对应请求提示“停车优先请求未生效” | LED1/2/3亮起或提示误写成已生效 |
| 长按KEY5/KEY6约3秒，松开再按 | 每次按住只切一次；松开后重新按可再切一次 | 长按连发或松开后不再响应 |
| 提示出现1秒后按另一键 | 新事件更新提示并重新保持约2秒，随后消失 | 提示提前按旧计时消失、长期不消失 |
| 在田字格拔掉电脑到HDMI-IN的线 | 左下显示“左摄无信号/需720p60”；前、后格继续更新；右摄仍待接入 | 整屏停止、前后摄断流或旧电脑图长期伪装为实时 |
| 重新插线并确认720p60活动信号 | 几个完整输入帧及输出帧后左摄恢复；其他摄像头不中断 | 一直不能恢复、恢复时串源、错误规格也被当作正常 |
| 原图下固定前、后视角各观察2分钟，再用田字格观察 | 记录原“下半段偶发闪动”的次数及触发条件 | 任何图内闪黑/错行/串源都需要记录，不能当作设计黑边 |

去噪采用因果3×3：输出(x,y)是当前像素及左侧/上方各两点组成的九点均值；边界旁路。这是基础均值效果，不是强去噪或道路算法。色彩分量在显示增益之后计算，DDR仍保存原始RGB565。

电脑看不到扩展屏时，先确认接口方向、电脑输出口、下载版本和重新插线；若仍失败，回传“未枚举”。能枚举但显示无信号时，回传Windows活动信号规格、刷新率和照片。不得把未枚举自动归因于滤波或DDR。
