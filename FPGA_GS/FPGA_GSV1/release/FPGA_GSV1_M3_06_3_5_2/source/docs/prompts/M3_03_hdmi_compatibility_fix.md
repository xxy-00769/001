# M3-03 3.2：修复27B1显示器“输入不支持”

继续FPGA_GSV1，实际定向修复、必要验证、构建并打包，不只返回方案。项目：`E:/zhoumian/FPGA/FPGA_GS/FPGA_GSV1`。先读README、开发指挥约定和本提示词；基于M3-02最终源码，保留用户改动和旧发布包，不重开发网络和文件工具。

## 事实与最新决策

- 用户加载M3-02 3.1后显示“输入不支持”，显示上板验收失败，暂停网口2分流/M4。
- Windows截图显示27B1直连RTX4060 Laptop GPU时活动信号为1920×1080、60Hz、RGB8bit、SDR；证明可接受电脑1080p60，不证明支持1080p30，也不是FPGA输出实测。
- `m31_timing.v`源码总2200×1125，有效1920×1080，+HS/+VS；74.25MHz理论行频33.75kHz、帧频30Hz；顶层AVI_VIC=34与该目标相符。源码没有明显的30/60标签混用，但不能替代实际PLL/输出信号测量。
- 首要怀疑为1080p30兼容性，仍须检查实际像素时钟、IO采样和MS7210。未读EDID或实测不得声称唯一根因已确认。
- 撤销上一任务默认允许降级1080p30的条件。目标改为这台显示器已知可用的标准1080p60。

## 实施顺序

1. 只读获取匹配27B1的EDID/模式信息，优先Windows现有显示设备/注册表，校验原始块及扩展。不要混淆板HDMI-IN模拟EDID与显示器EDID；不安装工具、不改Windows显示设置。无法读取时不阻塞已知1080p60目标。
2. 配置标准1080p60：像素148.5MHz，总2200×1125，H有效1920/前肩88/同步44/后肩148，V有效1080/前肩4/同步5/后肩36，+HS/+VS，行频67.5kHz，约16.667ms每帧。MS7210输入采样、时钟转发/相位、RGB8bit格式、AVI VIC16和checksum必须一致。依据芯片/原厂资料核对，不凭猜测改一堆寄存器，不能只改VIC标签。
3. 3.1早期148.5MHz构建曾像素setup −7.995ns、DDR −1.981ns，但后续优化只验证了30Hz。基于最终3.1分析真实关键路径，再针对来源选择、增益、色彩计算、OSD字符/坐标算术、DDR地址控制增加必要流水。RGB、同步、DE、坐标、来源和模式延迟统一；避免单拍长除法/取模/译码。不得只翻倍PLL就交付。
4. PLL已5/5，复用/调整已有资源，不假设第六个。按60Hz真实读请求重算DDR显示带宽、预取与欠载保护，保持所有权、跨帧旧返回排空、显式DRM及四格滤波边界。源视频与原图上传仍720p，不把60Hz输出当成60fps采集。
5. 保留单画面720p原像素居中、四格960×540直接采样、全部滤镜/中文/KEY/LED/停车优先、前摄独立上传及真实文件工具。不能永久移除处理或网络来称完整修复。
6. 必要时在最终输出路径提供编译期彩条/细线格源，旁路DDR像素但复用同一PLL、同步、IO和MS7210配置，定位格式与像素链。优先交付一个完整功能位流，只有仍有真实阻塞才补一个明确诊断版，不要求用户盲试大量版本。

## 有界排查与恢复策略

不通过false path、随意multicycle或降频约束隐藏真实同步路径问题。根据新增关键路径证据优化，不循环换种子/重复同一失败。

若1080p60仍存在明确且报告了的闭合阻塞，可交付标准720p60恢复版：74.25MHz、总1650×750、+HS/+VS、VIC4，先核对EDID/已有兼容性依据；单画面720p1:1、四格640×360，保留文件/网络完整功能。明确这是恢复显示的过渡版，1080p60未完成，不冒充最终1080目标，不再回800×480或未经确认的30Hz。

电脑→HDMI-IN仍按现有720p60输入，不能让用户改变电脑输入规格来修复FPGA输出；两条链分清。

## 验证与交付

- 核对真实PLL参数/频率和时钟约束，检查精确总像素/行数、同步宽度、DE、极性、VIC/checksum及像素对齐；不能仅用行为夹具预设正确时钟证明PLL正确。
- 最终生产路径跑完整尺寸单画面与四格，检查四来源像素、滤镜/OSD边界和跨帧恢复；保留受影响的DDR读、CDC/所有权回归，不展开无关算法/网络全量审计。
- 实际综合、布局布线及真实约束STA通过，外部IO未签核项如实标注。保留3.0/3.1，不自动烧录/固化/改网卡/防火墙/安装软件，不进入双网口/M4。
- 报告改动、原因、已证实与待测根因、实际输出格式、时钟/总数/极性/VIC、资源与setup/hold、新位流绝对路径、版本3.2、生成时间及SHA256。源码设定、数字检查、构建、显示器实测分开，不冒称上板通过。
- 最短用户验收：同一显示器和HDMI线，板HDMI-OUT直连屏，下载新完整位流，不先改电脑设置；应消除“输入不支持”，屏OSD识别1080p60（或明确的720p60恢复版）。随后检查单画面/四格/KEY6、文件右摄与电脑前摄。彩条可见不等于四路验收，格式接受后再测画质与fps。附可复制回传摘要。
