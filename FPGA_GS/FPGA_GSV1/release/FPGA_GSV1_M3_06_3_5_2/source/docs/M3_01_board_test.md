# M3-01 3.0 用户联调

保留已验收M2-02 2.1发布包作为回退。使用本轮3.0新位流，完整处理链开启；不需要测试2.1B。不自动烧录或固化Flash。

## 1. 接线及电脑设置

1. CAM0前摄、CAM1后摄及延长排线保持原接线。电脑HDMI-OUT→板HDMI-IN，板HDMI-OUT→MPI7001。电脑使用扩展显示，扩展屏活动信号1280×720、60/59.94Hz、SDR/RGB8bit，播放独立桌面或视频。
2. 网线接MES50HP**网口1**到电脑物理有线网口，或同一无隔离的千兆局域网。确认Windows显示链路速度1.0Gbps；本版未适配百兆。
3. 本机开发时只读观察到Realtek“以太网”为Disconnected，地址192.168.137.1；WLAN为10.168.29.76。下面192.168.50网段是隔离直连示例，尚未替用户配置。不要修改WLAN、虚拟机或TAP网卡。
4. 用户手动打开“网络连接”→对应物理以太网→属性→IPv4，记录原配置，再手动设置192.168.50.1、掩码255.255.255.0；直连不填网关/DNS。板卡固定192.168.50.2。确认无其他设备占用。测试后可手动恢复原配置。
5. 若Windows询问Python联网权限，用户按当前网络策略决定允许；工具不改防火墙。不用ping判断成功，因为本版未实现ICMP。使用ARP、工具心跳和画面判断。

## 2. 启动同一个联调工具

Python3.9+、tkinter、Pillow；开发电脑已存在这些依赖，未安装新软件，未使用numpy。若换电脑缺依赖，会直接报缺少模块，需要用户自行准备环境。

```powershell
cd E:/zhoumian/FPGA/FPGA_GS/FPGA_GSV1
python -X utf8 tools/m3/console.py --bind 192.168.50.1 --board 192.168.50.2 --right-fps 5 --front-fps 5 --auto allow --stats m3_stats.json
```

窗口放主屏，HDMI扩展屏独立输出左摄。5fps为请求上限，实际收发帧率看统计；开发电脑5秒软件回环仅约1fps，动态源会明显逐帧跳动，这属于本版已知性能限制。FPGA实物收发尚未测，不保证5fps或30fps。Windows使用进程内高精度等待避免成批追赶发送，未修改系统网卡或全局计时精度。窗口上方有停止/恢复右摄、模拟判定选择/按钮和保存前摄PNG。

无窗口采集统计命令（与GUI二选一，不能同时绑定50000端口）：

```powershell
python -X utf8 tools/m3/console.py --bind 192.168.50.1 --board 192.168.50.2 --right-fps 5 --front-fps 5 --auto allow --headless --seconds 60 --stats m3_60s.json
```

## 3. 逐步验收及可见结果

|操作|应看到|失败标志|
|---|---|---|
|用户加载3.0，启动工具，等数秒|双摄和HDMI保持原效果；工具rx_packets/heartbeat增长，heartbeat_age较小；右摄动态条带及RIGHT/帧号进入第四格|无心跳、ARP不出现，或第四格始终无信号。先核对端口1、千兆速度、IPv4及Python网络权限|
|KEY5逐次短按|前→后→左→右→田字格→前，右上角提示KEY5；田字格左上前、右上后、左下HDMI、右下RIGHT动态源|串源、冻结、错块、异常黑块，或循环只有旧四个视图|
|分别遮挡前、后镜头；HDMI扩展屏移动窗口|对应来源独立变化；隐藏再选中仍继续更新|其他窗口跟着同样遮挡，或隐藏来源冻结|
|切板上后/右/田字格，KEY6切二值/灰度/均值/Y分量模式|仅板上当前显示改变，电脑前摄窗口仍是CAM0干净彩色完整帧，无增亮/滤镜/中文；保存PNG可核对|电脑窗口变成后/右、变灰或含OSD，或帧长期不更新|
|KEY1、2、3短按，再KEY4短按|本地LED1左、LED2右、LED3直、LED4停立即响应；电脑每次生效事件只出现一次，含前摄帧号，自动allow时板上“前摄驾驶反馈”允许|LED等待网络才变、重复事件、来源跟随当前板上视图|
|长按KEY4，同时按KEY1～3|保持停车LED；提示请求受停车优先阻止；电脑不出现这些被忽略请求的新事件|其他意图覆盖停车，或被忽略动作仍作为新事件上报|
|选择manual，再按一个KEY1～4，立即点击允许/拒绝/未知|电脑显示RESULT_ACK接受；板上显示相应前摄驾驶反馈。2秒后回到未知；点击太迟应拒绝|旧动作或过期结果覆盖新动作，或失联仍保持允许|
|选择red或solid，重新按生效的KEY1～4|显示红色红灯/实线模拟告警；意图LED仍按本地按键含义，不因判定改变|告警改变LED定义，或显示成真实视觉检测结果|
|KEY6逐次短按、长按一次|原图→灰度→3×3彩色均值→二值→Y/Cb/Cr三栏→原图；提示KEY6和实际模式，长按只切一次；四格接缝不互相污染|多次连发、窗口边界滤波串色、OSD错位|
|“停止/恢复右摄发送”|停止后保留最近完整图，约3秒后右摄无信号，其余三路及前摄上传/按键继续；恢复后下一完整帧自动更新|半帧发布，或停止右摄拖死其他来源|
|关闭工具/断网，再重启/重连|约2秒后反馈未知；旧DDR读排空后释放网络持有槽；恢复会话和完整帧，不用重新烧录|显示停采、槽耗尽、旧判定复活、重连永久无图|
|持续同时收前摄、发右摄，切视图和滤镜、按键|统计中完整帧持续增长，控制有ACK，显示保持正确；记录60秒统计和可见帧率|任一业务导致另一业务永久无进展或原图颜色受影响|

可选一次丢包对照：关闭当前工具，用下列参数启动。每帧故意缺片时，右摄应不发布残缺图；其他三路与控制仍正常。结束后恢复正常命令，下一完整帧应恢复。

```powershell
python -X utf8 tools/m3/console.py --bind 192.168.50.1 --board 192.168.50.2 --right-fps 5 --front-fps 5 --drop-every 200 --auto allow --stats m3_loss.json
```
