## 证据支持的修正与边界

传感器OV3660已经在ID1及3.5.6实物中两次读取3660。现有SCCB配置有ACK、错误处理和19项强制回读，G1表明该流程成功。不是继续猜芯片型号、SCCB地址或修改颜色以掩盖异常。

关键数值4344=2×2172，其中2172为实际写入的HTS。OV3660原厂v1.3第94页table5-2规定4709默认VS宽度2行，第97页fig5-7显示短高电平VS同步脉冲以及高有效HREF图像行，第96页table5-2给出4740复位值20和VS/HREF极性位。旧3.5.6用23，并将原始VS高解释为同步、HREF高解释为图像。

4344像素且只有一条连续有效行，强烈支持旧配置与上述输入约定不匹配：仅把2行长的同步区间当成了数据，真正图像区间被VS门控排除。它不是随机丢少量像素、颜色顺序错误或简单末尾一拍错位的特征。交换VS/HREF物理信号会产生行频级帧边界，与实测约12.6次/秒不符。

本轮定向模型使用完整HTS2172、VTS1322、1280×720 RGB565及2行VS，四种VS/HREF反相组合均运行实际cam3660_dvp和video_capture_status。只有双同步反相组合重现4344/1/03；正常同步组合得到921600/720/00，并逐像素检查独立的帧/行/列编码。这个实验是对现场签名的区分性解释，不能代替实际引脚示波测量，也不证明现场每个原始边沿均已测出。
