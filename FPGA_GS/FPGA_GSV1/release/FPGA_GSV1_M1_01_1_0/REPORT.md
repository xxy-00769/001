# M1-01 双摄基础版交付报告

版本：FPGA_GSV1 M1-01 1.0。日期：2026-10-20（Asia/Shanghai）。

## 一、本轮改了什么

- `rtl/board/fpga_gsv1_top.v`：从旧工程提取必要的板级 PLL、两个 OV5640 配置/接收和 DDR PHY 连接，去掉旧单摄宏、算法、KEY8 诊断模式、HDMI-IN 实例和亮度增益。CAM0=cmos1=来源 0 前摄，CAM1=cmos2=来源 1 后摄。
- `rtl/capture/capture_pipe.v`：两路独立的两拍像素/帧号/时间元组延迟，使原始几何结果在下一 VS 前交给缓存 owner。两路都持续观察输入，不由 KEY5 控制采集。
- `rtl/reuse/fram_buf.v`、`frame_buffer_owner.v`：统一复用完整帧所有权和末拍完成修复；各来源两个独立 DDR 帧槽，完整帧且 720 行 DDR 完成后才发布，显示和待发布槽禁止覆盖。新增按来源地址和整帧丢弃计数，保留帧号、毫秒时间、固定尺寸/格式、有效状态和异常计数。
- `rtl/frame/dual_ddr_arbiter.v`：两路写、两路读分别轮询，锁定一个 burst 到最后数据拍，正确使用 HMIC_S 的 WREADY/WLAST 和 RVALID/RLAST。隐藏视角也保持采集和读取。
- `rtl/board/m1_keys.v`、`rtl/display/m1_view_select.v`、`m1_osd.v`：20 ms 按键消抖；KEY5 每次按下切换一次，在显示帧边界提交，标签与画面同源；固定 16×16 字库显示“前摄/后摄”。KEY1～4 为左/右/直/停，LED1～4 互斥保持，默认停车，停车键保持期间优先。
- `rtl/reuse/mpi7001_timing.v`：保留 V5.1 已获用户稳定反馈的显示时钟/窗口结构，输出对齐坐标供中文使用。800×480、约 59.927 Hz；中央 640×360 为完整原始帧的偶数行列缩小图，原 DDR 图不含文字。
- `vendor/`、`constraints/mes50hp.fdc`、`flow.tcl`、`scripts/`：只提取必要的 DDR/行缓存 IP、适配约束及配置/控制 RTL；增加独立可重复构建、检查和打包入口。逐文件旧来源及复制时哈希保存在 `vendor/reuse_manifest.json`，原工程和归档未修改。

## 五、用户测试步骤与应看到的结果

1. **断电接线。** 按现有双目模组接法连接两个独立输入，CAM0 放前方，CAM1 通过计划使用的延长排线放后方，核对排线方向及原有电压/转接方式。HDMI-OUT 接 MPI7001 800×480 小屏并正常供电；本轮不接 HDMI-IN。不要带电插拔摄像头。
2. **上电并烧录本报告正式 SBIT。** 用现有 PDS 下载流程选择该绝对路径，核对版本和文件哈希。等摄像头/DDR 初始化完成（建议先等约 5 秒）：中央应出现前摄实景，左上角黄色“前摄”，四周黑边；LED4 亮、LED1～3 灭。两路摄像头内部状态不再占用这四个意图灯。若只用 JTAG 临时配置，断电后需重新下载；本报告不声称已经写入启动 Flash。
3. **KEY5 短按。** 每次按住约 0.1～0.2 秒后释放，第一次应在下一显示帧边界变成后摄实景和“后摄”，第二次回前摄和“前摄”。长按约 2 秒，只切换一次；释放后再按才能再次切换。标题和画面来源应一致，不出现上下半幅来自不同摄像头。
4. **遮挡验证来源和更新。** 前摄模式遮住 CAM0，中央应变暗/被遮挡；移开应恢复前方动态画面。遮住 CAM1 时前摄不应被遮挡；按 KEY5 后应看到被遮挡后摄和“后摄”。在前摄模式下移开后摄遮挡并在其前移动一个与前方不同的物体，切回后摄应看到当前后方内容；反向重复。用不同物体、连续切换确认不会串源或冻结。RTL 已检查隐藏路采集和帧发布不依赖 KEY5；本轮没有加入 PC 计数读取接口，板上定量帧率尚未测量。
5. **KEY1～4。** 依次短按：KEY1→仅 LED1 亮（左）；KEY2→仅 LED2 亮（右）；KEY3→仅 LED3 亮（直）；KEY4→仅 LED4 亮（停）。释放后保持当前意图。按住 KEY4 再按其他意图键仍应停车；释放停车键后，再按其他键才能改变。意图键不应切换摄像头或滤镜。KEY6 本轮不改变原图。
6. **检查颜色和边缘。** 两路分别放红、绿、蓝物体，核对颜色无明显互换；中央区域应为 640×360，位于屏幕 (80,60)，检查四边、底部及运动物体，不能有残留条带、错块或切换撕裂。缩小显示最后一行取原图第 718 行（从 0 计），这是 2 倍抽样；原始 DDR 第 719 行仍已写入并纳入仿真比对。
7. **排线稳定性。** 保持两路同时连接，连续观察、切换约 1～2 分钟。延长后若仅后摄出现花屏/闪屏/冻结，先记录版本、标题、是否前摄正常、异常位置与触发操作；断电后改回短线对照，再断电换回延长线。记录排线长度和走线方式，不用反复改 FPGA 参数替代接线对照。

**可直观看到的效果：** 中央前/后真实摄像头画面、左上角“前摄/后摄”随 KEY5 同步变化，以及四个互斥意图灯。所有这些现场效果目前均待用户烧录确认。
