# 数据来源、候选池与防泄漏方案

## 来源选择

首选 S²TLD：上游 [Thinklab-SJTU/S2TLD](https://github.com/Thinklab-SJTU/S2TLD) 说明有5,786图、14,130实例，1920×1080及1280×720，含红黄绿/off/wait on、光照变化、易混淆尾灯。项目与中国道路任务相关，但具体路口、横排比例、日夜和箭头覆盖必须从下载数据核查，不能靠名称保证。

上游 README 直接链接作者 `yangxue/S2TLD` 的 Hugging Face 数据仓库。仓库代码 LICENSE 为 MIT；官方链接的数据卡声明 **Apache-2.0**，本批按该数据卡记录数据许可，不把代码MIT冒充图片许可。保存两处原文和不可变下载版本 `82f6494de63f6412b8112c8413c3559723dd3cfd`。若压缩包内有更具体或冲突条款，暂停使用并核对。保留许可证、NOTICE和论文引用，不以下载成功代表无条件可发布原图。下载SHA须与HF LFS SHA一致。

其他来源不自动混入：Bosch、LISA、DTLD、BDD100K的道路域、许可及注册条件各不相同；没有逐项核实和获取许可前只列后备，不能用第三方镜像的“公开”代替授权。不使用网络随意抓图。S2TLD若夜间/行人/可辨箭头覆盖不足，后续补充许可可核验的独立来源或有授权的新采集，不能从四个开发视频偷补最终测试。

## 清单与首批目标

- `data/archive_provenance.json`：来源版本、下载URL、完整压缩包SHA和许可依据（成功下载校验后生成）。
- `data/candidates.csv`：实际抽取图片逐图SHA、源XML、分辨率、源标签类别、原始框尺寸、候选场景编号、审核状态；不是合格真值。抽样使用确定性分组选择，保留源标签原文。
- `data/baseline_inventory.csv`：旧证据85张原图名文件的清单，只作回归。`raw`后缀不能保证干净：目视已见auto/SC_BT_55_raw、auto/SC_YJ2_50_raw中存在框线/UNKNOWN字样；auto/geometry等历史中间产物按污染风险隔离，不能批量导入训练。
- `annotations/examples.json`、`artifacts/annotation_examples.png`：人工规则样例，首轮审核待复审，不计入合格训练数。

首批目标400图：约280张含灯，120张有挑战性负背景；允许负背景图中同时存在已完整标注的真灯。横排、昼夜、小目标、饱和白芯、遮挡、尾灯、LED招牌、反光均应有覆盖。配额是采集目标，不预先宣称已达到。优先按场景去重，再作属性分层，不能为了凑满400重复相邻帧。若S2TLD无法满足全部配额，实际清单中写缺口；源XML只是导入候选，需补body/灯面关系与可辨性。

## 本轮实际收集结果

已校验1080p包304,993,489 bytes、SHA256 `c81b968f8c365415c5f76f2fbfa5503b0bccdcb7926e75abf472cbc52b07a5de`，含1,222图片及配对XML。抽取400张候选，**合格数0**。源标签合计803个：red408、green271、yellow23、wait_on99、off2。以上是源标签分布，不是复核后的有效灯体/灯色数量。

源框短边分布：<8px 1个、8～15px 130个、16～31px 440个、≥32px 232个，且原框未必符合本项目body定义；极小目标和off的覆盖仍严重不足。400图时间线上均匀抽取用于筛选，尚未完成相邻帧去重。SHA完全重复0对；dHash128阈值6发现87对疑似近重复，见reports/near_duplicate_candidates.json，必须人工确认、去重或绑定同组。57个时间间隔候选段中覆盖54段，不能据此宣称54个独立路口。

对40张联系表样本作过目视初筛，确认有中国道路横排/竖排、夜间雨天眩光、尾灯/反光和辅助LED文字，但没有给400图批量签署完整标注。亮度阈值仅检出17张低平均亮度图，不能将该数当夜间数量（灯光和曝光会使夜图很亮）。行人灯、可辨箭头及不同路口的完整覆盖仍待逐图统计。

**源wait_on不能直接当某种灯色。** 已目视核实样本0266的wait_on框[1422,129,1678,175]是“直行车辆入待转区”的辅助LED文字；本项目灯体检测将它记辅助标识/硬负区域，保留源语义。样本0307也有此类文字。其他wait_on逐项判断，不一概转换。源red/green框还可能包住计时器，应按本规范重画body/emitter。

已从官方许可图像制作尾灯、LED文字、雨夜路面反光三个硬负区域，以及一个可辨左箭头例子，见annotations/hard_negative_examples.json与artifacts/hard_negative_examples.png。这些都是待复审的局部例子，并非已完成的120张负样本或整图真值。纯负图数量、逐图去重和标注复核仍有缺口。

## 分组与冻结

1. 建立 `site_id / intersection_id / recording_id / sequence_id / scene_id`。所有来自同一路口的录像，及同一连续场景的所有帧、裁剪、增强图、近重复图组成连通组，整体进入同一个split。拍摄时间改变不自动解除同路口约束。
2. 源文件名前缀只能当候选 sequence_id，不能证明路口独立；先对联系表及场景缩略图复核。元数据不够时 `group_status=unverified`，禁止自动生成正式train/val/test。
3. SHA全重复和感知哈希近重复跨split检查；再检查背景/路口重复。相邻帧抽稀（例如至少2秒且感知变化充分）只是候选去重，不是独立性证明。
4. 确认分组后，以组为单位大致70%训练/20%开发/10%保留核查，优先保证组不跨界，再考虑类别/昼夜分布。小批次不足以覆盖各类时报告缺项，不移动单帧凑比例。
5. **SC_BT、SC_BT2、SC_YJ、SC_YJ2全片，以及其所有截图/裁剪/旧holdout统一标 regression**，禁止进入新模型训练或最终泛化测试。旧holdout与开发属于同批道路场景，不能重新宣称独立测试。
6. **最终泛化测试另建 external_test_locked**：来自未参与模型/阈值/分辨率选择的新路口和新录像，建议至少10个独立路口、昼夜均有；冻结图像SHA、组清单、标签版本、评估脚本和阈值。未收集前明确写“暂无独立泛化测试集”。该集不能用于INT8校准。看结果调参后该集转为开发，另建新测试。

`data/split_plan.json` 保存状态，当前可以全为unassigned。400张候选/甚至400张通过复核也只验证流程；可靠性需要更广的独立场景与足够置信区间。

## 训练前放行

必须同时具备：明确许可；干净原图；逐图漏标/错标复核签署；body定义统一；不可辨颜色/箭头为unknown；全部分组核实及无交叉泄漏；候选导出和RKNN FP16构建成功；资源小规模实测完成。`scripts/check_readiness.py` 输出各项状态，任一项不足就不训练。禁止以模型预测置信度、伪标签数量或训练mAP绕过此门槛。
