# M4-03-demo-r1 首份可运行交付

FPGA保持断电。本版只运行本地录像/模拟车辆，无业务UDP、无伪造EVENT，不修改RTL、原LIVE算法、协议、网络或系统服务。

## 双击使用

- 启动：`E:\zhoumian\FPGA\FPGA_GS\FPGA_GSV1\orangepi\oneclick\启动智驾录像演示.cmd`
- 停止：`E:\zhoumian\FPGA\FPGA_GS\FPGA_GSV1\orangepi\oneclick\停止智驾录像演示.cmd`
- 集中SSH配置：同目录 `config.json`，当前 `orangepi@10.168.29.122:22`；换管理网只改 `ssh_host`。
- 浏览器自动打开 `http://127.0.0.1:18080/`，通过SSH转发到板端127.0.0.1:8080。默认640宽、JPEG70，目标15fps。

入口有中文控制台，成功/失败都保留窗口。已有密钥/agent时不需输入密码；普通密码认证时在SSH窗口输入，不保存。新建转发可能出现单独SSH窗口；密码认证时远端操作与转发可能分别询问一次密码。保持转发窗口运行；关闭它会中断预览，远端仍运行，重新双击启动可复用服务并重建转发。关闭启动控制台或浏览器不会停止远端；用停止入口结束它。无需sudo，无需FPGA或有线业务链路。

入口先核对项目PID、参数和端口：可安全停原项目LIVE再切录像；无关8080/18080占用会给出PID/命令行并拒绝，不杀其他任务。重复启动复用同一PID，停止只结束本录像PID及该入口创建的转发。原入口创建、被复用的转发保留。未配置自启。

## 最短可见操作

1. 双击启动，默认夜间录像70秒开始。画面中有交通灯框、灯色/人工控制方向、大箭头和模拟停车标志；页头明确“本地录像/模拟车辆”。无需阅读JSON。
2. 点“夜间路口70秒”：十字路口、直行车道、自动模式。红灯停车；点“请求直行”仍停车，不报警。点“强制行驶”才出现红色边框、闯红灯模拟告警和模拟行驶。点“停车（优先）”立即停止并解除告警。
3. 点“路口转灯103秒”，等待真实画面转绿，模拟车辆起步、直行箭头亮绿。选择左转/右转所在车道会因灯组方向未关联而未知，不自动放行；离开标定区域也未知。
4. 点“日间道路32秒”，进入独立道路变道模式；点“请求左”，左实线时保持直行；“强制跨左线”才出现实线告警和模拟左变道。停车或清除可解除。
5. 点“日间虚线32秒”，点“请求右”：当前右侧虚线证据稳定时允许右变道，绿色边界/箭头显示在视频中；灯色未知不阻止道路模式。此段右邻车道为明确的人工空间标定，线型来自实际像素。黄昏片右侧可能是路缘块，邻车道未确认时不允许。标线证据不够的帧仍未知/保持直行，不能将整段称为持续识别成功。
6. 四视频下拉可任意切换，支持播放/暂停、进度条跳转、循环、重新开始及640/1280宽。变帧率片定位需短暂等待原生解码；切换/跳转/循环清理旧驾驶和感知。暂停超过0.5秒后感知失效，模拟安全停车。
7. “保存原图及叠加”保存成对原图JPEG、叠加JPEG和同帧JSON，页面显示远端路径；原片不改。下方标定说明和JSON默认折叠。

录像中的真实车辆不会因模拟停车而停止：这是两个独立状态。当前没有车辆/行人/斑马线检测，也没有真实执行器或真实KEY闭环。

## 性能与验证

完整媒体信息、场景与限制见 `../m403/素材与视觉边界.md`。四片已上传并核对SHA256，重新运行传输脚本四片全跳过。四段均实际解码并在Edge浏览器经SSH转发播放，两种宽度每段约10.3秒窗口，不用离线吞吐代替播放。

| 视频 | 640处理/预览新帧fps | 1280处理/预览新帧fps |
|---|---:|---:|
| SC_BT | 14.46 / 14.17 | 12.07 / 12.16 |
| SC_BT2 | 15.01 / 15.01 | 14.46 / 14.46 |
| SC_YJ | 14.97 / 14.77 | 12.4 / 12.4 |
| SC_YJ2 | 14.96 / 14.67 | 14.94 / 14.65 |

短窗口计数边界可能差一帧；15.01不表示设置了高于15fps。预览只统计新epoch/源frame身份，不计重复JPEG、重画或HTTP请求。最终页面每浏览器最多1个最新JPEG图片请求在途；服务端等新帧，不再叠加客户端限速。MJPEG接口仍保留，默认不用。慢浏览器只拿最新帧，不阻塞处理。落后按实际PTS跳过旧源帧，保持正常播放速度。

640宽分项约：解码6.4–17.7ms、预处理7.5–12.6ms、灯体ROI0.02–1.7ms、车道几何10.6–28.3ms、规则0.03–0.04ms、叠加4.6–9.6ms、JPEG2ms。1280宽叠加约9.6–21.0ms，JPEG7.4–7.8ms；复杂城区未达到15fps，主要成本为车道几何、叠加和JPEG，默认推荐640。详细按片采样见 `../m403/evidence/stage_summary.json`。没有神经网络推理，inference字段为CPU视觉算法耗时，不是NPU耗时。

约10秒窗口内，640逐新帧图龄最大113–291ms，1280最大119–300ms；软件时间轴滞后有界，详细采样见performance_final.json，没有持续增长。**图龄从板端原帧解码完成起算**，浏览器以状态请求估计主机单调时钟偏移，显示估计上界，含处理/SSH传输，不是摄像头到网页端到端延迟。这些是该窗口内浏览器实际收到新帧的最大估计值。最终30.98秒逐新帧窗口处理14.78fps、预览14.59fps、最大图龄295ms、视频位置增加31.00秒；未积压。记录见 `final_30s_preview.json`。

规则自动检查9项通过，使用模拟感知，只证明停车优先、强制、过期/未知、方向、独立变道、报警到期与重置。真实原片视觉的红停/绿行/强制红灯、实线保持/强制实线、日间虚线允许（右邻车道人工标定）、暂停、切换与自然循环证据另存浏览器目录。原生VFR跳转修复后另做定位/循环定向验证且同一实例通过，旧尝试失败记录保留，不作当前验收通过。

已实测启动、同PID重复启动、停止/重复停止、外来端口占用拒绝；只使用测试进程短暂占用已释放8080，未终止其他业务。`release_checks.json`确认原LIVE十个文件与备份SHA256逐一一致。FPGA未上电，本轮没有LIVE或双口联调。
