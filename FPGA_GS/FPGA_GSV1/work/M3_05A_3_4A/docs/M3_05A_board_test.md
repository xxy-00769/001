# M3-05A 3.4A：一次最短观察

本候选用于定位左摄第一个失败环节，**不代表HDMI已修复**。唯一可加载文件和时序边界以本轮交付报告为准。保留3.3旧包；用户自行临时加载，不固化Flash。

沿用原接线及电脑活动信号1280×720、60/59.94Hz，不改网络或显示设置。HDMI-OUT仍为1920×1080p60。

1. 加载交付报告指定的唯一候选，等待约3秒。KEY6切到原图，KEY5到左摄。看左上“左摄”旁的L码，同时看真实桌面/视频是否出现。正常链路应为L7且画面持续变化；若黑屏，记录稳定L码，不再按“需720p60”反复改分辨率。
2. KEY5切到田字格，左下应为电脑HDMI实景，标签旁有同一L码。记录单画面与田字格是否一致。L7但仍黑屏、停帧或错块，表示这些被动计数不足以证明实际像素正确，也必须回报。
3. 保持原电脑工具15fps设置，KEY5看右摄动态视频数秒，确认仍流畅。无须重跑历史长测、滤镜穷举或摄像头全尺寸验收。

| 码 | 首个未通过的观测阶段 |
|---|---|
| L0 | MS7200初始化done未到；并不证明I2C物理应答成功。 |
| L1 | 连续50ms未见原接收帧计数变化；可能为输入时钟/VS链未活动，不能单凭此码区分。 |
| L2 | 见到输入VS，但原720p行场总量或参考帧率判定未通过。 |
| L3 | 格式通过，但原1280×720有效像素/完整帧监测未健康。 |
| L4 | 采集健康，但尚无完整DDR帧，或发布计数250ms未变化。 |
| L5 | DDR已有发布，当前来源未选中；切换后的短暂过渡允许，左摄/田字格下持续L5异常。 |
| L6 | 来源选中，但读欠载保护有效，或50ms未见显示DE活动。 |
| L7 | 上述观测通过，且近期有显示DE；不等于HDMI图像正确已获实物验收。 |

只需回传：“3.4A，左摄单画面是否有图/L码，田字格左下是否有图/L码，右摄15fps是否仍流畅”。若码跳变，说明跳变范围。后摄绿点本候选不处理、不宣称消除。
