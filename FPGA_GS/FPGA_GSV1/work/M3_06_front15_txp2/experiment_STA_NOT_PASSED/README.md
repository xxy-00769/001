# TXP2：未通过外部STA，不是合格修复版

当前板上保持TXOBS1；本目录不是推荐功能发布，不自动下载。只有用户明确同意一次受控对照后才请其手动加载。

唯一主动变量：网口2PLL转发TXC由相对数据+1ns改+2ns；PHY strap/MDIO、RX、4mA FAST、协议、主机服务和其余功能保持。源码在相邻目录，actual build快照在status.json路径。

生产ARP2/控制10/前摄长包8的字节、引脚重组FCS、IFG及既有管理门控检查通过。内部慢/快角setup/hold/recovery/removal通过。外部条件模型（附加内部TX延时0、PCB差分偏斜0；两项未实测）setup−0.214ns、包括固定TQ路径的hold−0.297ns；取完整120条路径排除40条恒零三态使能TO后，80条真实DO路径的最差hold仍−0.263ns。公共外部相位窗口[2.214,1.737]ns为空，不应继续仅移相。

约束根时钟设0.2ns不确定度，但实际此生成时钟相对路径报告采用工具0.05ns；不得声称0.2ns已经覆盖本输出。若另显式要求相对0.2ns，示意窗口进一步收窄至[2.364,1.587]ns。数据表要求仍各1ns，未降低。这里不做外部/PCB签核。

为什么仍提出一次可选对照：实际PHY延时读8575、bit13=0由strap决定，而有效TX strap未知。ODDR前约97万帧均CRC好，主机窗口仍1CRC。保持PHY/驱动只变TXC相位，可区分相位是否对当前错误敏感；若接受，先10秒检查自动会话/完整帧和硬件CRC，不要求换线或重启服务。

判定：完整接收接近15fps且CRC/组帧/socket全零才允许继续60秒；零CRC但零/低完整帧不是通过。若系统性CRC/无前摄，立即记录失败并恢复已有TXOBS1，不继续盲扫相位。若仍零星CRC，说明这一变量没有消除问题。不把实测好转改写为STA通过或唯一根因确认。

额外已完成的IO库特性检查：同bank实际ODDR/OUTBUFT及4/8/12/16mA合法档，仅编译/PNR/报告，不生成位流；4mA tco+pad慢角范围3.844～4.924ns与生产吻合，16mA约3.366～4.167ns。这是工具模型，不是示波器测量，不证明驱动增大能修复实物；当前候选未改驱动。全部原始证据在reports/NET2_front15_quality_20261023。
