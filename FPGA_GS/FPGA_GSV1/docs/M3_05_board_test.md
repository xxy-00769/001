# M3-05 3.4 待发布后的最短验收

仅在交付报告明确STA通过并提供推荐位流后执行。若报告为未放行，请勿使用build目录的失败产物。

沿用原接线、原HDMI-IN活动信号1280×720 60/59.94Hz、原1080p60显示器和已流畅的15fps工具设置。工具、命令及网络配置未变。不要求换线、重配分辨率或重复历史70秒测试。

1. 用户自行加载交付报告唯一推荐3.4位流；等待摄像头和HDMI初始化。应继续输出标准1920×1080p60，中文和按键提示位置正常。
2. KEY6切到“原图”，KEY5选择左摄单画面，再切田字格。应看到电脑扩展屏的真实桌面/动态视频：单画面1280×720原像素居中，田字格左下为左摄；不应持续黑屏、错块或串源。
3. KEY5选择后摄，观察原先绿点明显的边缘并轻微移动镜头前物体，再看田字格右上。预期新增绿点消失，边缘完整、颜色连续；未裁边或涂黑。如果绿点仍在，验收失败，不能以滤镜变淡当作通过。
4. 保持右摄工具原15fps播放，KEY5看右摄及田字格数秒。应保留3.3已流畅的动态视频，前/后/左/右四格各自独立，前摄预览保持彩色原图。若右摄明显卡回约1～3fps、黑块或错源，属于回归。
5. 快速按KEY6循环处理模式，再回原图。应无新增画面/OSD错位；无需重做全部滤镜数值或按键/LED历史验收。

若左摄仍未恢复，只需回传持续出现的L码和画面照片，无需重新设置已确认的分辨率。刚上电短暂L0/L1或切换等待不算持续故障。

| 码 | 所在环节 |
|---|---|
| L0 | MS7200初始化未完成 |
| L1 | 未观察到输入像素时钟活动，或时钟停止至少约2ms |
| L2 | 有输入时钟，但约50ms没有VS活动 |
| L3 | 输入行场总量或参考时钟测得帧率未通过 |
| L4 | 采集有效尺寸/完整帧监测未通过 |
| L5 | 尚无完整DDR发布，或约250ms未更新发布 |
| L6 | 当前选中的HDMI显示读欠载 |
| L7 | 上述阶段已通过，画面保护/显示就绪等待；正常画面时不显示 |

诊断只观察状态，不开关采集、修改输入或关闭保护；状态经过同步、超时和OSD传播，不能当成示波器的逐拍记录。若L7长期有画面保护提示仍无真实画面，也算失败，需要结合该环节继续定位。

回传最简格式：`版本3.4；左摄单/四格：正常或L码；后摄边缘：绿点消失/仍在；右摄原15fps：流畅/回退；模式切换：正常/错位。`
