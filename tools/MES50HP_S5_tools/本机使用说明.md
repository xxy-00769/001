## 日常使用

优先使用本机新增的启动文件，不使用原包的 `run_windows.cmd`，因为它会选择系统默认 Python。

1. 双击 `启动模拟端.cmd`。
2. 双击 `运行模拟测试.cmd`。
3. 观察握手成功、序号更新，模拟 LED 在两秒后归零。
4. 模拟测试结束后，回到模拟端窗口按 Ctrl+C 停止。

需要真实板端测试时，在本目录 PowerShell 运行：

```powershell
.\启动客户端.cmd --count 20 --log .\board_test_001.json
```

日志不覆盖同名文件，再次运行应更换日志文件名。

真实测试前，必须获得接通实体 UDP 的 FPGA 位流，并按该版本发布记录核对网口、地址、端口。原包声明当前 V1 位流尚不发送 UDP，不能据此版本无应答判断电脑安装失败。真实测试按 README 配置对应有线网卡，保留原配置；本次部署没有修改网卡、防火墙，也未测试板端硬件。

## 已完成验证

软件模拟端与客户端在回环地址完成握手、LED 请求和十次状态查询：发送 12 包，应答 12 包，超时、非法包和不匹配包均为 0。模拟 LED 状态在两秒租期后归零。记录见本目录 `simulation_*.json` 和同名 `.txt`。

这证明本机工具可运行，不证明 FPGA 实体通信或视频传输完成。本工具没有视频接收功能。
