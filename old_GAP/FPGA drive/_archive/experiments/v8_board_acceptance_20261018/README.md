## 现场步骤（下载须另获明确许可）

1. 板卡供电，摄像头连接 CMOS1，HDMI 连接显示器，JTAG 连接开发电脑；
   连接和供电按实物板说明执行，不带电插拔不明接口。
2. 获得许可并下载上述 v8 后，分别记录工具下载结果和显示器画面；
   文件名/哈希、成功下载日志与现场画面一起证明受测版本，DONE 不能单独证明版本。
3. 先拍完整 HDMI 画面：摄像头模式不应常驻 `TEST`，检查 HUD 帧号是否推进，
   移动摄像头检查上/下半幅和四周边界。仅保存一张照片不能证明连续稳定。
4. 连续观察五分钟并保留录像/起止时间。记录冻结、黑屏、撕裂、重复行、叠色偏移，
   不将“未看见异常”报告为精确帧率/延迟测量。
5. 用已有测试图卡快速检查居中实线、虚线、空白、斑马线候选，记录预期与实际；
   图卡只验证受控场景，不算真实道路识别。原图可由开发电脑显示供摄像头拍摄，
   该电脑是调试素材工具，不是最终系统必需处理器。
6. 补充清晰道路实线/虚线及室内桌柜/线缆各类画面，记录候选误检、漏检和分类错误。
   用于查找问题，不据少数无标注图卡计算准确率。
7. 不以热插拔未知摄像头接口测试掉线。遮挡只是无内容场景，不证明停帧/断链超时已实现。
   若自然出现停帧，记录旧结果是否残留；该功能缺口另列，不强称已解决。
