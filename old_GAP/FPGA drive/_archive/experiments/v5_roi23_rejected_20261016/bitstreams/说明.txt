烧录文件说明
================================================

当前道路标线测试版本：
5_road_roi23_precision_cmos1.sbit
    摄像头接 CMOS1，固定显示，不再轮播。
    原图上绿色为白色标线候选，青色为黄色标线候选。
    仅识别整幅摄像头画面的下三分之二：720 行画面从零基第 240 行开始，上三分之一保持原图。
    识别范围内再使用道路梯形，并增加两侧中性暗背景检查、连续 10 行支持，减少宽面板和零碎区域的误检。
    白、黄候选都进行横向宽度过滤，宽度门限随深度从 12 增至最多 96 像素。
    五组 RTL 回归及完整编译通过；现有时序约束满足，但摄像头输入延时约束仍未补齐。
    图像与同步信号统一延迟；并非只移动检测色块。
    强曝光、偏色、宽标记、偏离中心的弯道仍可能漏检，零碎误检也可能残留。
    这是标线候选提取，不是虚实线分类、道路语义识别或变道决策。
    道路图片请尽量全屏、居中，本版不自动定位网页内图片；新版实拍识别效果尚需验证。
    4_road_markings_filtered_cmos1.sbit 为上一版（黄色宽度过滤），保留回退。
    3_road_markings_cmos1.sbit 为未加宽度过滤的版本，也保留。
    1_main_red_edge 和 2_test_cmos2 继续保留。

只烧这个文件夹里的文件。generate_bitstream 里的是编译原始输出，不用管。

1_main_red_edge.sbit
    主用版本。摄像头接 cmos1 口。
    画面 = 原始彩色 + 物体边缘描红边。

2_test_cmos2.sbit
    测试版本。摄像头要插到板上另一个摄像头座子（cmos2 口）。
    用来验证第二个摄像头接口是不是好的。
    画面同样是彩色 + 红边。

烧录步骤：
    PDS -> 菜单 Tools -> Configuration
    -> 左边选 Boundary Scan
    -> 中间空白处右键 Initialize JTAG chain
    -> 在 PANGO 方框上右键 Program...
    -> 选 .sbit 文件 -> Run
