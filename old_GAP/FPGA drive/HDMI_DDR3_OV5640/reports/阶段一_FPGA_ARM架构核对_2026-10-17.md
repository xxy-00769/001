## 5. 实际硬件与接口条件

| 项目 | 已证实的范围 | 未确认/风险 |
| --- | --- | --- |
| FPGA | 用户称盘古 K50；PDS 配置 PGL50H、-6、FBG484；历史 JTAG ID 0x00521899 | 核心板/底板 PCB 型号与版本未确认；MES50HP 只是匹配候选 |
| 存储 | 主代码 DDR 地址行15/列10/Bank3、DQ32；已有视频 DDR 通路 | 实物 DDR/Flash 料号、容量、板版本需资料确认；不能用配置参数证明实物容量 |
| 视频 | 两组 8bit DVP 端口与 I2C/复位，编译选择 CMOS1；输出 MS72xx 配置与 HDMI 像素 | 双目传感器型号/同步/左右输出与接法未确认；无四路并行通路 |
| 外接 ARM | 当前已选 Orange Pi 5 普通版 / RK3588S，官方列有千兆网口/USB与 Linux 支持 | 是否已购/套餐、实物系统和驱动状态未核实；比赛风险不阻塞实施 |
| 高速互连 | 当前顶层没有以太网、PCIe、USB 视频或返回控制端口/实例 | 板卡是否焊接/引出、双端例程、驱动与电气均未证实 |
| 按键/行为输出 | 现有 top 只有初始化/心跳类输出，没有比赛控制按键输入 | 不得借用 JTAG/相机/LED 引脚接 ARM；行为输出与初始化输出必须区分 |

MES50HP 参考手册与比赛板介绍确实列有网口/PCIe。参考手册描述 PCIe 边缘接口和
由主机提供参考时钟；这只使“网口优先、PCIe 备选”成为可核查的候选，不证明实物可用。
手册自身有“两个网口”与局部“一个端口”等表述差异，必须以实物版原理图为准。

更重要的是，参考手册 40pin 表的 AB13/AA10/U12/T12 等引脚与现有 DVP 约束有重合，
因此摄像头可能已占用该扩展口；不能把 40pin 当成整组空闲 ARM 总线。
当前 fdc 的 CMOS 数据输入存在 VCCIO=3.3 / LVCMOS12 并列配置，板内 IO 电压不能据此武断确定。
本次不修改这项旧配置；接新设备前必须按原理图核对电压、方向、地线、上拉、时钟与占用。

## 6. 单路最小架构与带宽判断

一页连接方案见同目录《单路_FPGA_ARM连接方案_2026-10-17.md》。
职责可以确定：FPGA 继续做真实采集、必要 CDC、颜色/去噪等预处理、基础候选与显示叠加，
不是只接线转发；ARM 做轻量预训练模型、复杂场景、状态机、按键/命令及素材读取。
不把 ARM 的推理结果称为 FPGA 完整神经网络；也不把 FPGA 候选称为语义识别。

**首选候选：实际两端均具备的千兆以太网 + 厂商成熟双向参考工程 + ARM Linux 接收服务。**
ARM 管理会话，FPGA 图像上行、ARM 结果/控制下行。先证明双向数据，再接真实图像，
再测试带源帧号的固定框回传；固定框明确标通信测试。当前尚无匹配双端参考工程，
不据此开写完整 MAC/协议栈，更不采购未核实板卡。

PCIe 仅在已有完整 RC/EP、连接件、时钟复位供电和 ARM 驱动/DMA 参考时优先级才可能提高。
两块板有 PCIe 字样不等于能插上互通；不以 PC 作为最终 Root Complex。
若两种候选都不具备，经两次有假设/结果的实质尝试仍无法成立，应提交替代硬件方案由用户决策，
不转回无限自研加速器。当前缺资料，不算已经做了两次硬件联调失败。

以下仅是无压缩有效载荷算术，不含报头/空隙/丢包，也不是实测：

| 档位 | 每帧 | 有效载荷速率 |
| --- | --- | --- |
| 1280×720 RGB565，假设30fps，单路 | 1,843,200 B | 55,296,000 B/s，442.368 Mbit/s |
| 初始通信候选640×360 RGB565，5fps，单路 | 460,800 B | 2,304,000 B/s，18.432 Mbit/s |
| 原尺寸同档位四路 | 每路1,843,200 B | 合计1,769.472 Mbit/s，已超过单个1G链路的标称速率 |

因此先打通小图真实链路，不承诺全尺寸四路原始图能塞进单1G链路。
后续根据比赛素材可辨性与实测再决定分辨率、帧率或成熟压缩/多链路，阶段一不实现四路调度。
现有160×90缩略图模块只是可参考旧实验，不强制作为新路线输入，也不把它当模型输入已集成。
四路需要确认四个独立源、输入时钟/接口、扩展板和带宽；复制一路画面、USB摄像头直接进 ARM
都不能冒充已经实现四路 FPGA 并行采集。
