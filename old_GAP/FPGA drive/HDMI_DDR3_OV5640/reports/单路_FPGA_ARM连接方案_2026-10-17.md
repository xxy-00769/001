## 目标数据流

```text
真实摄像头 CMOS1 / DVP
    -> FPGA 采集、颜色/灰度与滤波、基础标线候选、帧号/完整性
    -> 原有 DDR / 显示缓冲 -> FPGA 结果叠加 -> HDMI 显示器
    -> 未叠色分析图 + FPGA 基础结果
    -> 高速双向链路（首选候选：以太网；待实际接口确认）
    -> ARM Linux：接收、轻量预训练模型、状态机、按键与告警管理
    <- 带会话号 / 通道号 / 源帧号 / 有效位的结果和控制命令

官方 U 盘 -> ARM USB Host / 解码 -> 同一高速链路 -> FPGA 处理 / 显示
           （素材回送是后续功能，尚未实现，不以电脑播放替代最终独立运行）
```

## 接线与资源决策

| 项目 | 已知 | 冻结前必须补齐 |

| 以太网（首选候选） | MES50HP 参考手册列有板载网口，但尚未证实用户实物与之相同 | 双端 RJ45/PHY、引脚/电压/复位/时钟、FPGA 双向参考工程、ARM 驱动 |
| PCIe（备选） | 参考板手册有 PCIe 边缘接口，不代表任何 ARM 可直接连接 | ARM Root Complex、FPGA Endpoint、转接板、供电、REFCLK/PERST、DMA 驱动/例程 |

两端均可收发，没有 SPI 式总线主从。FPGA 内部 MAC/PHY 连接按**实物版原理图与匹配例程**
实施，不从当前未使用端口推定空闲 GPIO。未确认之前不接飞线，也不把 USB 转串口当 USB Host。

## 最小数据契约（草案，非已实现）

- 通道先固定为 0，采集时生成帧号，图像与 FPGA 候选共用源帧标识。
- 显示保留现有 1280×720 RGB565；首次链路测试暂定发送 **640×360 RGB565_LE、5 帧/秒**，
  不裁剪、不叠色。此为通信试验档位，不是模型输入尺寸、比赛性能承诺或已达到的实测值。
- 图像头含协议版本、会话号、通道号、帧号、采集时间计数、尺寸、格式、分片偏移/总长与校验；
  ARM 仅发布完整且校验通过的帧。最多一帧处理中、一帧最新等待；满时丢旧等待帧并计数。
- 结果回传相同身份、有效位/类别/置信度及坐标；坐标是发送图左上为原点、整数像素、
  右/下边界不含的矩形。640×360 映射全幅 1280×720 时乘 2；模型内部缩放必须逆映射。
- 几何只叠在保留的**同一源帧**上；不直接沿用旧模块“上一帧结果配当前帧”的方式。
  预留帧超过暂定 500ms 本地计时上限就释放并显示未知；帧错配也丢弃，不无限拖延画面。
- 断链、无效、坏帧、重启、过期立即撤销外部结果/驾驶结论；重复包不续命，旧会话不接收。
  控制命令带独立序号、有效期与 ACK，重传不重复执行。最终超时参数按实测确定。
