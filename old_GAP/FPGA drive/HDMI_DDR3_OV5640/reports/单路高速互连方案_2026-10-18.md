# 单路高速互连：接线与实施边界

日期：2026-10-18。结论：**采用 MES50HP 的 ETH1 与 Orange Pi 5 普通版网口直连，作为单路联调路线；资料核对完成，不代表已互通。** 取代旧连接方案中的“底板待确认”和旧报告后续顺序。不恢复 v12，不把本文计为真实收发交付。

## 接线、角色与数据流

```text
OV5640/CMOS1 -> PGL50H采集/跨时钟/必要预处理/缓存 -> MAC/UDP -> 板载RTL8211E
                                                               |
                                      MES50HP ETH1 RJ45 == Cat5e/6网线
                                                               |
                            Orange Pi 5 RJ45 -> Linux UDP -> 推理/主要决策
                                                               |
FPGA显示/控制 <- 校验、会话/源帧匹配、超时处理 <- 结果/命令回传 -----+
```

两板分别使用各自匹配电源；不接 GPIO/RGMII 飞线，不跨板接供电。FPGA 与 ARM 是以太网对端，不是 SPI 主从。FPGA 内部 MAC 驱动 PHY 的 TXC/MDC，PHY 提供 RXC；MDIO 双向。USB 测试素材以后由 ARM 读取，电脑不在最终运行链路中。

## 带宽预算与最小数据约定

初始目标是RGB565、640x360、5fps，不承诺已达到。MTU1500、IPv4无选项20B、UDP8B、预留应用头64B，每包图像最多1408B；含以太头/FCS/前导码/帧间隙后，每包额外130B。公式：`(图像字节数 + ceil(图像字节数/1408)*130)*8*fps`。

| 计划输入 | 图像上行线速预算 | 判断 |
| --- | --- | --- |
| 单路640x360 RGB565 5fps | 约20.14Mbps | 首个图像交付目标；未测吞吐。 |
| 单路1280x720 RGB565 30fps | 约483.24Mbps | 仅预算，不提前追求此性能。 |
| 四路640x360 RGB565 5fps | 约80.55Mbps | 仅带宽预查；不证明四路输入可接。 |
| 四路1280x720 RGB565 30fps | 约1932.96Mbps | 超出一个千兆口，不能承诺。 |

先给上行设不超过800Mbps的规划预算，为控制、波动留余量；不是实测可用带宽。回传小结果另算，双向视频/素材不能当作免费流量。四路摄像头的真实连接/并行采集尚无依据，本轮不展开。

设计约束，尚未实现或发布协议：RGB565_LE、逐行从左到右/从上到下，640x360来自1280x720的2x抽取计划；坐标原点左上、像素整数，矩形为半开区间，明确尺寸/缩放映射。头部预算包含版本、消息类型、64bit会话号、通道号、32bit源帧号、格式/尺寸、分片偏移/总长、有效标志和CRC32；头部网络字节序，像素LE。CRC32覆盖校验字段置零后的头和本片载荷，整帧另校验，不依赖UDP checksum。

ARM发起握手，FPGA确认新会话后清缓存/旧结果；会话标识需跨重启避免重用，断链重建。接收按偏移重组、限长、限时，整帧完整才交推理；旧会话、重复、无效和过期结果丢弃。以FPGA本地捕获年龄判超时，试运行先设500ms，不比较两板未同步时间戳。控制带独立序号与ACK，重复命令只重复ACK、不重复执行；断链/超时清空结果并显示未知。

至少保护一帧在处理、最多一帧等待，满时丢等待帧/新帧并计数，不覆盖正在使用帧；640x360双帧像素预算921600B，另需包缓存，不在本轮重造内存系统。几何只叠到匹配源帧并按坐标变换显示；暂做不到时仅显示带帧号的非空间测试状态，不能把旧框贴新画面。复用v11简单按键交互，主要决策归ARM；实线阻止时实际动作明确为直行/停止，请求方向不得冒充执行动作。

## 缺什么、下一交付与停止条件

所需资源仅为已选Orange Pi 5、可启动的适配Linux及存储/匹配电源、一根合格四对网线；是否到货/可登录未知，不默认已购齐，不新增板卡采购。RK3588S比赛性能限制保留风险，不宣称合规。

下一唯一目标：**真实双向小数据收发**，不是识别。独立v13先做网络小包序号/CRC/ACK与可观察状态；ARM到手后验收真实往返，再逐项交付真实摄像头图像到达ARM、带源帧号测试结果返回、FPGA正确显示/控制。固定框仅通信测试；PC/模拟端不能替代ARM验收。每一步以保存的收发数据和板端现象为证据，不以新增文档计进度。

本阶段状态：资料级接口判断通过，阶段一整体仍为进行中；尚无可直接验收的应用双向版，ARM实物/系统及电气运行状态未确认。获得授权后停止资料扩展，进入上述小数据实现；遇同一阻塞两次有依据尝试仍无解就停并提出替代，不复活v12或换参数续轮。
